# Hostess portfolio template — Elegant (Cloudflare Workers)

Crimson editorial portfolio for the `hostess-pl` factory. Provisions from the same `hostess.json` contract as `template-hostess-cf`, with Abril Fatface + Raleway on a deep crimson ground. Tally style **Elegancki** routes here via `resolveTemplateChoice` in `scripts/tally-normalize-core.mjs`.

## Local development

```bash
pnpm install
cp .env.example .env
pnpm dev
```

Open `http://localhost:4321/` — the review toolbar appears automatically during `pnpm dev` on localhost.
